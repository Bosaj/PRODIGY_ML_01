# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [1.0.0] - 2024-11-17

### Added
- Linear regression notebook predicting `SalePrice` from engineered total square footage, bedroom count, and bathroom count (Ames housing dataset).
- Model evaluation (RMSE) and diagnostic visualizations (distribution, correlation heatmap, predicted-vs-actual, residuals).
- Kaggle-style submission file generation.
- `requirements.txt`, MIT `LICENSE`, and this changelog.
- `.github/workflows/ci.yml`: GitHub Actions pipeline validating notebook integrity.

### Changed
- Rewrote `README.md` with an accurate project description, tech stack, and usage instructions.
